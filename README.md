# 🌄 Scenery Web Page

This is a simple and beautiful **Scenery Web Page** created using **HTML and CSS**.

## 📌 About Project

This project displays a beautiful scenery image in full screen with a text section placed over the image.

The page contains:

- A full-screen scenery image
- A heading **"Scenery"**
- A description text
- Transparent background for the text section
- Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Full-screen image
- Responsive design
- Text overlay on image
- Transparent background using `rgba()`
- CSS positioning
- Simple and attractive design
